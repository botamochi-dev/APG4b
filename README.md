# [C++入門 AtCoder Programming Guide for beginners (APG4b)](https://atcoder.jp/contests/apg4b)

APG4b を解くための作業場所です。**Zed** と **VS Code** のどちらでも使えます。
ビルドや答え合わせは `tools/apg4b.py` がやるので、エディタはどちらでも同じ結果になります。

## 必要なもの

- MinGW の g++（`C:\Program Files (x86)\mingw64\bin`）
- Python 3
- （VS Code の場合）拡張機能「C/C++」（初回に推奨拡張機能として表示されます）
- （Zed の場合）追加のインストールは不要。C++ の補完（clangd）は Zed が自動で用意します

## Zed で解く

フォルダごと開きます: `zed C:\Users\skybl\dev\work\APG4b`

| やりたいこと | 操作 |
| --- | --- |
| タスク一覧を開く | `Alt+Shift+T`（またはコマンドパレット `Ctrl+Shift+P` →「task: spawn」） |
| 問題を準備 | タスク「問題を準備」→ ターミナルで `EX4` などを入力 |
| 実行・答え合わせ | .cpp を開いた状態でタスク「実行・テスト」 |
| 前回のタスクをもう一度 | `Alt+T`（task: rerun） |
| デバッグ | ブレークポイントを置いて `F4`（debugger: start）→「開いているファイルをデバッグ」 |

一度「実行・テスト」を動かせば、そのあとは **コードを直して `Alt+T`** を繰り返すだけです。

設定ファイル: `.zed/`（タスク・デバッグ・エディタ設定）、`compile_flags.txt`（補完やエラー表示用のコンパイル設定）

## VS Code で解く

- `Ctrl+Shift+B`: 実行・答え合わせ
- `Ctrl+Shift+P` →「タスクの実行」: 問題を準備・実行・テストなど
- `F5`: デバッグ

設定ファイル: `.vscode/`

## 問題の解き方（共通）

1. **問題を準備する**
   タスク「問題を準備」で `EX4` などを入力。またはターミナルで:

   ```
   python tools/apg4b.py new EX4
   ```

   章のフォルダ（EX4 なら `E/`）に `EX4.cpp` が作られ、問題ページから
   ひな形のプログラムと入出力例（`E/tests/EX4/`）を取ってきます。

2. **プログラムを書く**

3. **タスク「実行・テスト」で実行・答え合わせ**
   - 入出力例がある問題 → 全部の例で答え合わせして `AC` / `WA` を表示
   - 入出力例がない問題 → 普通に実行（入力はキーボードから）

4. すべて `AC` になったら AtCoder に提出

## その他の操作

| やりたいこと | 方法 |
| --- | --- |
| 自分で入力して試す | タスク「実行」 / `python tools/apg4b.py run E/EX4.cpp` |
| 入出力例で答え合わせ | タスク「テスト」 / `python tools/apg4b.py test E/EX4.cpp` |
| 1行ずつ止めて変数を見る | ブレークポイントを置いてデバッグ（Zed: `F4` / VS Code: `F5`） |
| 入出力例を自分で追加 | `tests/<問題名>/3.in` と `3.out` を作る |

## 判定の意味

| 表示 | 意味 |
| --- | --- |
| AC | 正解 |
| WA | 出力が違う（正しい出力とあなたの出力が並べて表示されます） |
| RE | 実行時エラー（配列の範囲外アクセスなど） |
| TLE | 2秒以内に終わらなかった（無限ループなど） |
| CE | コンパイルエラー（エラー箇所はエディタ上にも赤線で出ます） |

## コンパイルの設定

AtCoder と同じ GCC・C++23 でコンパイルします。学習用に次の設定も入れています
（設定は `tools/apg4b.py` の `CXXFLAGS`）。

- `-Wall -Wextra`: ミスしやすい書き方を警告
- `-D_GLIBCXX_DEBUG`: `vector` の範囲外アクセスなどをその場でエラーにする
- 日本語が文字化けしないよう UTF-8 に統一

## フォルダ構成

```
B/tests/EX1/       入出力例（1.in, 1.out, ...）
B/output/          ビルドしてできた exe（git には入れません）
include/bits/      bits/stdc++.h
tools/apg4b.py     ビルド・実行・テスト用スクリプト
```
